## 四、环境与门禁（每条命令前必做）

```powershell
Set-Location D:\_APP_CODE\ImageEdit
. scripts\env.ps1          # 每个 pwsh 会话、每次 cargo build / 运行 exe / Start-Process 前必须 source
$out = cargo build -p imageedit-ui 2>&1
"BUILD_EXIT=$LASTEXITCODE" # 必须单独核验 = 0（失败时旧 exe 仍会过门禁！）
& .\target\debug\imageedit.exe --selftest --probe-dialog   # 唯一自退出探针，~1.8s 内 EXITCODE=0
"EXITCODE=$LASTEXITCODE"
```

- **env.ps1 不 source 的后果**：构建时机器级 CC/CXX 指向 LLVM clang → cxx.cc 对 MSVC 头 20 个错误；
  运行 exe 时 Qt bin 不在 PATH → "imageedit.exe - System Error" 对话框 + 进程卡死（必须 Stop-Process）。
- 其他 `--probe-*`（adjust/marks/menu/layers/resize/settings）**永不退出**：
  `Start-Process … -RedirectStandardOutput target\x.log -RedirectStandardError target\x.err -PassThru`
  + `Start-Sleep 7` + `Stop-Process -Id <pid> -Force`，2 秒后再 `Get-Process imageedit` 确认已死。
- **门禁对 QML 运行时绑定错误是盲的**：每次提取后必须检查 probe stderr **0 行**
  （曾 3 个面板全部 EXITCODE=0 但 stderr 满屏 TypeError）。
- 应用单实例：第二次启动会 handoff 退出；卡死的首实例会阻塞 handoff —— 启动前先杀旧实例。
- 文件路径一律**绝对路径**。
- 一次只跑一个 cargo build（target 锁）。

## 五、QML 提取规则（血泪总结，必须遵守）

1. **绝不把裸 id 引用转成 `host.<id>`**：QML 的 `id` 不是根对象的属性，跨文件 `host.<id>` 求值为
   undefined，运行时 TypeError，门禁抓不到（已烧 3 个面板）。
   正确做法：每个被引用的外部 id 在面板文件里声明 `required property var <id>`，实例处传 `<id>: <id>`。
   `host.` 只用于 EditorContent 的**已声明属性/函数**（`root.x` → `host.x`，裸 `fn()` → `host.fn()`）。
2. 提取前先全量枚举：块内 `root.`/`bridge.`/裸函数调用/所有 EditorContent id 出现次数
   （Python 正则 + 断言），块外对块内 id 的反向引用（如 4022 行 Esc 处理器引用 layerContext →
   给面板加 `contextVisible` 属性 + `closeContext()` 函数适配）。
3. 面板文件 = `import QtQuick` + `import com.imageedit`（引用同模块类型 ToolButton/MenuRow/…必须）
   + 根元素（**不能用 `component` 关键字**，qmlcachegen AOT 不支持）+ `id:` + required props
   （插在 id 行后）+ 块体（去掉首尾 `}`）。
4. 面板独占的函数/Timer 可随块迁移（先 grep 确认无其他调用点）。
5. Python 提取脚本：真实 UTF-8 字符（勿用 `\u` 转义，注意 「」vs “”）；每个 id 替换加
   `(?<!host\.)` 负向后顾（防上一步产物被二次匹配）；逐行锚点断言 + repr() 报错；
   `root.` 点数与裸词点数分开断言（注释含裸词）；Timer 追加在面板闭合 `}` **之前**。
6. 绝不用 PowerShell Get/Set-Content 改源码（GBK 会损坏中文）；用 edit/write 工具或带显式 UTF-8 的 Python。
7. edit 工具陷阱：多行 old_string 首行前导空格会丢失 —— 锚点放行中或用 Python。
