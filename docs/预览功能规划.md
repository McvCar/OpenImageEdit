# 类 macOS「预览」(Preview) 功能规划文档

> 版本：v0.5（草案）
> 目的：分析 macOS Preview 的功能集合，规划一个可跨平台复刻的功能规格（feature spec），供后续开发排期与架构设计使用。
> **已定平台/技术栈**：跨平台原生（Rust 核心 + Qt/QML 界面，cxx-qt 桥接）。
> **已定范围**：仅图像（**PDF 暂不纳入**）；包含 **RAW / PSD**；**不包含 3D 与智能功能**（移除背景、Live Text）。
> **已定分发**：便携版 + 安装包。
> **已定关键决策（v0.5）**：冷启动门槛（**v0.6 修订**：所有尺寸 ≤ 2000ms，目标 ≤ 1000ms）、PSD 以合成预览为主、多窗口为主、色彩管理阶段 3 做基础转换（详见第 8.1 节）。

---

## 1. 产品定位

macOS「预览」是一款**轻量、启动快、免安装即用**的查看器与轻编辑器，核心价值：

- **快速查看**：几乎所有常见图像与文档格式，双击即开。
- **轻量编辑**：标注、裁剪、调色、格式转换，无需专业软件。
- **PDF 处理**：阅读、标注、填表、页面组织、加密。（**本项目暂不纳入**，见第 2.4 节。）
- **批量与导出**：批量转换、尺寸调整、导出多格式。

设计原则：**查看优先、编辑够用、零学习成本、系统级集成**。

## 3. 功能模块清单

### 3.1 查看 (Viewer)

- 打开方式：双击、拖拽、打开对话框、从其他 App 分享。
- 视图模式：连续滚动、单页、双页；缩略图侧边栏。
- 缩放：缩放适配、实际大小、放大/缩小、手势缩放（触控板/滚轮）。
- 平移：拖拽、滚动条、手势。
- 全屏、幻灯片播放。
- 旋转 / 翻转（仅视图或写入）。
- 窗口背景色设置。
- 多窗口为主（每个文档独立窗口，契合系统双击/打开方式）；多标签为后续可选增强。

### 3.2 标注 (Annotate)

- 文本：添加文字框、字体/字号/颜色。
- 形状：矩形、椭圆、线条、箭头。
- 手绘：自由绘制（画笔粗细/颜色）。
- 高亮：荧光笔高亮。
- 签名：手写/摄像头/键盘输入签名，可复用保存。
- 放大镜 (Magnifier)：局部放大。
- 便签 (Note)：附注气泡（PDF 注释）。
- 选择工具：矩形选择、椭圆选择、Smart Lasso、Instant Alpha。
- 密文遮盖 (Redaction)：永久擦除敏感内容（PDF）。
- 标注可移动、缩放、删除、复制样式。

### 3.3 图像编辑 (Image Edit)

- 裁剪 (Crop)：自由/比例约束。
- 旋转 / 翻转。
- 调整尺寸 (Resize)：像素/百分比，保持宽高比。
- 调色 (Color Adjust)：
  - 曝光、对比度、高光、阴影
  - 饱和度、色温、色调
  - 棕褐色 (Sepia)、锐度 (Sharpness)
- **选区图层（核心）**：
  - 框选 (Marquee)：矩形 / 椭圆 / 自由套索 (Lasso)。
  - 将选区提取为**独立图层**，可移动、缩放、删除。
  - **跨图片复制粘贴**：从一个文档复制选区图层，粘贴到另一个文档（跨文档剪贴板）。
  - 图层可调整顺序、透明度、可见性。
- ~~一键移除背景 (Remove Background)~~（**本项目不纳入**）。
- ~~Live Text：图像文字识别与选取~~（**本项目不纳入**）。
- ~~图像描述 (Image Description)：无障碍文本~~（**本项目不纳入**）。
- 色彩管理：阶段 3 做**基础色彩空间识别与转换**（sRGB / Display P3 / Adobe RGB）；Assign Profile、Soft Proof、完整 ICC 留阶段 4。

## 4. 开发阶段规划

### 阶段 0 — 技术验证 (Spike)

- 技术栈已定（Rust + Qt）；验证 **cxx-qt** 桥接与 Qt/QML 部署链路。
- **建立冷启动基准**：测量 Rust 核心 + Qt 壳的进程启动、解码、首帧时间，用于敲定 MVP 门槛。
- 验证各格式解码可行性（MVP 先 JPEG/PNG/GIF/BMP/TIFF/WebP；后续 RAW、HEIC、PSD）。
- 验证选区图层模型与跨文档复制粘贴的实现路径。
- 验证便携版打包与安装包生成链路（Windows / macOS / Linux）。

### 阶段 1 — MVP（最小可用：快速冷启动预览 + 基础编辑）

**目标**：能替代系统默认看图工具，且**冷启动到首帧显示尽可能快**（这是本产品的差异化核心）。

> **进度（2026-10-17）**：查看外壳（打开/缩放/平移/全屏/快捷键/拖放）、旋转翻转、撤销重做、另存、便携打包与打包自检**已完成**；裁剪、调整尺寸、选区图层 UI、多窗口**未开始**。打包版冷启动实测 tiny 448 / small 495 / medium 670 / large 1163ms，全部达标。详见 `docs/阶段1-MVP.md`。

**1) 快速冷启动预览（核心指标）**

- **目标**：双击文件后，从进程启动到首帧可交互的时间压到最低。**量化门槛（v0.6，据阶段 0 实测修订）**：所有尺寸 **≤ 2000ms**（上界），**目标 ≤ 1000ms**；其中大图（≤50MP）为最紧的一项（阶段 0 实测 D3D11 路径 1246ms）。原 v0.5 分级门槛（小图 < 300ms / 中图 < 600ms / 大图 < 1.2s）实测不可达：主因是 Qt/QML 固定开销约 290–425ms（窗口显示 + RHI 初始化 + 首帧），与图片大小无关，详见 `docs/阶段0-技术验证.md`。
- **实现要点**：
  - 只解码**首帧/预览所需分辨率**（渐进式 / 缩略图优先），先出模糊或缩略图，再异步解码全分辨率。
  - **前后端并行**：UI（Qt 主线程）与解码/渲染（工作线程池）彻底分离，主线程绝不阻塞。
  - **预热与缓存**：启动时预热常用解码器；缩略图/解码结果做磁盘缓存。
  - **延迟加载**：仅在真正需要时才初始化重量级模块（PDF、RAW、3D 等）。
  - **懒加载二进制/插件**：格式解码器按需加载，避免拖慢启动。
- **查看**：打开（双击/拖拽/命令行/打开对话框）、缩放（适配/实际/手势）、平移、全屏。
- **格式（MVP）**：JPEG、PNG、GIF、BMP、TIFF、WebP。

**2) 基础编辑**

- 裁剪 (Crop)：自由 / 比例约束。
- 旋转 / 翻转。
- 调整尺寸 (Resize)：像素 / 百分比，保持宽高比。
- 导出 / 另存为。
- **选区图层（核心）**：
  - 框选 (Marquee)：矩形 / 椭圆 / 自由套索 (Lasso)。
  - 将选区提取为**独立图层**，可移动、缩放、**删除**。
  - **跨图片复制粘贴**：从一个文档复制选区图层，粘贴到另一个文档。
- 撤销 / 重做。
- 多窗口、基础快捷键。

**3) 非目标（放到后续阶段）**

- 完整调色、标注/签名、批量、RAW/PSD、PDF（不纳入）。

### 阶段 2 — V1（图像编辑 + 标注）

- 调色全套（曝光/对比度/高光/阴影/饱和度/色温/色调/棕褐色/锐度）。
- 标注：文本、形状、箭头、手绘、高亮、放大镜、签名。
- 选择工具：矩形/椭圆/Smart Lasso/Instant Alpha。
- 多格式导出（HEIC、JPEG-2000、TIFF）。
- 批量操作。
- 检查器（信息、EXIF）。

### 阶段 3 — V2（专业格式与体验完善）

> 原 PDF 阶段**已移除**（本项目暂不纳入 PDF）。

- **RAW**（DNG / 各厂商 RAW）查看与转换。
- **PSD**：以**合成预览为主**（读取扁平化合成图，支持查看与导出）；图层级查看作为后续可选增强。
- 幻灯片、**基础色彩管理**（sRGB / Display P3 / Adobe RGB 识别与转换）。
- 打印。
- 便携版 + 安装包正式发布。

### 阶段 4 — V3（增强 / 差异化）

- OpenEXR / HDR 支持。
- **完整色彩管理**（Soft Proof / ICC、Assign Profile）。
- **多标签界面**（可选增强；默认仍为多窗口）。
- 更多导出与批量能力打磨。
- 平台系统集成（分享、最近文件、快捷键完善）。
- ~~3D 模型查看（STL/OBJ/USD）~~（**不纳入**）。
- ~~一键移除背景 / Live Text / 图像描述等智能功能~~（**不纳入**）。

## 5. 技术选型（已定：Rust + Qt）

> **平台/技术栈已确定：跨平台原生（Rust + Qt）**，覆盖 Windows / macOS / Linux。

### 5.1 总体分层

| 层 | 技术 | 说明 |
| --- | --- | --- |
| UI 层 | **Qt 6 + QML/Qt Quick** | 跨平台原生外观、手势、高 DPI、文件对话框、打印（UI 方案已定：QML） |
| 桥接层 | **cxx-qt** | Rust ↔ Qt 类型安全绑定（已定） |
| 核心层 | **Rust** | 解码、编辑、渲染、文档模型、撤销栈、缓存 |
| 并发/启动 | Rust `rayon` / `tokio` + 线程池 | 解码与渲染并行，保证冷启动速度 |

### 5.2 关键库（Rust 生态优先）

| 用途 | 候选 crate | 备注 |
| --- | --- | --- |
| 基础图像解码/编码 | `image` | JPEG/PNG/GIF/BMP/TIFF/WebP 等，MVP 主力 |
| 高性能/大图 | `libvips` (libvips-rs) | 大图、缩略图、批量 |
| 渲染 | `skia-safe` 或 Qt Quick 场景图 | 合成与显示 |
| EXIF/元数据 | `kamadak-exif` | 检查器信息 |
| RAW | `rawler` 或 `libraw-rs` | 纳入；阶段 3 |
| PSD | `psd` crate 或自研解析 | 纳入；阶段 3 |
| PDF | ~~`pdfium-render` 或 `mupdf-rs`~~ | **本项目不纳入** |
| 3D | ~~`gltf` / `tobj` + Qt 3D 或 wgpu~~ | **本项目不纳入** |
| OCR/智能 | ~~`tesseract` 绑定 或 平台 API~~ | **本项目不纳入** |

### 5.3 目录结构建议（Cargo workspace）

```
ImageEdit/
├─ Cargo.toml            # workspace
├─ crates/
│  ├─ core/              # 文档模型、编辑操作、撤销栈（纯 Rust，无 UI）
│  ├─ decode/            # 格式解码器（按需加载）
│  ├─ render/            # 渲染/合成管线
│  └─ ui/                # Qt 桥接 + QML/Widgets
├─ qml/ 或 ui/           # QML 或 .ui 资源
└─ docs/                 # 本规划文档
```

**依赖引入前必须核对实际已用库**（遵循仓库约定）；新增依赖需评估体积与冷启动影响。

## 6. 架构与数据结构要点

- **文档模型**：`Document { sourcePath, format, layers/annotations, editHistory, metadata }`。
- **非破坏性编辑**：编辑以操作栈/图层形式保存，渲染时合成；导出时烘焙。
- **标注模型**：`Annotation { type, geometry, style, content, pageIndex }`，与图像/PDF 页坐标解耦。
- **格式适配器**：统一 `Decoder` / `Encoder` 接口，按扩展名或魔数分发。
- **渲染管线**：解码 → 色彩空间 → 编辑图层 → 合成 → 显示/导出。
- **撤销/重做**：命令模式 + 历史栈。
- **多页/多窗口**：`Document` 支持多页容器（多页 TIFF、GIF 动画等）；App **以多窗口承载多文档**（每文档独立窗口，已定 v0.5）；多标签为后续可选增强，不作为默认交互。

## 7. 风险与难点

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| RAW / PSD 解码复杂 | 厂商私有、格式庞大 | 分阶段、优先成熟开源库 |
| 色彩管理 | 不同色彩空间一致性 | 引入 ICC/色彩管理管线 |
| 格式写回精度 | 有损格式再压缩 | 明确默认导出参数，保留原格式 |
| 跨平台一致性 | 字体、渲染、DPI 差异 | 统一渲染后端，抽象平台层 |
| 性能 | 大图/多页/RAW 内存占用 | 分块解码、GPU 加速、缩略图缓存 |
| 冷启动回归 | 依赖增多拖慢启动 | 懒加载解码器/模块，持续基准测试 |

## 8. 已确认事项与待确认事项

### 8.1 已确认（v0.5）

1. **平台/技术栈**：跨平台原生，Rust 核心 + Qt/QML，**cxx-qt** 桥接。
2. **UI 方案**：**QML + Qt Quick**。
3. **MVP 范围**：快速冷启动预览 + 基础编辑（裁剪/旋转/调整尺寸/导出/**选区图层跨图复制粘贴/删除**）。
4. **PDF**：**暂不纳入**（仅图像）。
5. **RAW / PSD**：**纳入**（阶段 3）。
6. **3D 模型 / 智能功能**（移除背景、Live Text、图像描述）：**不纳入**。
7. **分发方式**：**便携版 + 安装包**同时提供。
8. **冷启动量化门槛（v0.6 修订）**：所有尺寸 **≤ 2000ms**（上界）、**目标 ≤ 1000ms**；首帧可交互时间（spawn → 含图首帧）。原 300/600/1200ms 分级经阶段 0 实测不可达，原因与实测数据见 `docs/阶段0-技术验证.md`。
9. **PSD 支持深度**：**合成预览为主**（扁平化合成图查看 + 导出）；图层级查看作为后续可选增强。
10. **多标签 vs 多窗口**：**多窗口为主**（每文档独立窗口）；多标签作为后续可选增强。
11. **色彩管理范围**：阶段 3 做**基础色彩空间识别与转换**（sRGB / Display P3 / Adobe RGB）；完整 ICC / Soft Proof 留阶段 4。

### 8.2 待确认（Open Questions）

- 当前无未决问题。原 4 项（冷启动门槛、PSD 深度、多窗口/多标签、色彩管理范围）已于 v0.5 全部确认，见第 8.1 节第 8–11 项。
