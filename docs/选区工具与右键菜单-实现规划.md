### 1.2 缺什么（也就是本次要做的）

1. 只有矩形一种产出方式；椭圆/套索**几何算法在 core 里已经有，但 UI 完全没有入口**。
2. 选区用完即清（`crop/copy/cut/erase` 后 `selW=0`），撑不起「反选 / 边界 / 平滑 / 羽化」这类**二次运算**。
3. 选区在 QML 里是 4 个 float，无法表达「非矩形 / 带洞 / 软边」，也没有锚点让 Rust 参与。
4. 没有右键菜单，没有参数对话框。
5. 所有消费端（抠图、删除）只认 `Selection::Rect`，且是**硬边二值**——羽化无从落地。

## 2. 三个关键设计决策

### 决策 A：选区真值迁到 Rust 的 `SelectionMask`（alpha 覆盖图）

```rust
// crates/core/src/selection.rs（新增）
pub struct SelectionMask {
    pub bounds: Rect,      // 画布坐标，只覆盖有意义的区域（省内存）
    pub alpha: Vec<u8>,    // bounds 尺寸，0..=255 覆盖度
}
```

- **为什么不用矢量**：反选（带洞）、边界（距离场）、平滑（形态学）、羽化（模糊）四个操作本质都是像素域算子。PS 内部选区就是 8-bit mask，矢量只是画完后立即光栅化。
- **为什么不用整画布 mask**：8000×8000 的 u8 是 64 MB；局部 `bounds` 让常见矩形选区只有几 MB。
- 矢量「形状描述」仍然保留（`SelShape`），**仅供 QML 拖手柄时重建 mask**，不作为真值。

```rust
pub enum SelShape { Rect(Rect), Ellipse(Rect), Polygon(Vec<(f32,f32)>) }  // 自由套索与多边形套索同构
```

- 自由套索 = 拖拽采点后闭合的 `Polygon`；多边形套索 = 单击加点后闭合的 `Polygon`。**内部完全复用**，只在交互层区分。

### 决策 B：QML 保留「交互态」，Rust 持有「语义态」（双份但职责清晰）

| 层 | 持有 | 生命周期 |
|---|---|---|
| QML | `selTool`、拖拽中的临时顶点、多边形套索的待闭合点列 | 一次手势内 |
| Rust `Session.selection` | `SelectionMask` + `feather` + `version` | 跨操作持久 |

手势结束（松手 / 双击闭合）→ QML 调 `bridge.sel_set_*(...)` 一次性提交；Rust 算 mask、bump `version`；QML 监听 `sel_version` 变化 → 拉 `bridge.sel_outline()` 重画蚂蚁线、拉 `sel_rect` 摆手柄。

**好处**：拖拽期间零跨语言往返（现有 `EdgeHandles` 也继续流畅）；所有几何运算只在 Rust 里有一份实现，可单测。

### 决策 C：羽化是**参数**，不是烘焙进 mask

PS 里羽化后蚂蚁线位置不变，只有实际影响范围变软。若把 mask 直接模糊，轮廓会外扩、`bounds` 变大、`sel_rect` 漂移，视觉与 PS 不符。

```rust
pub struct SelState {
    pub mask: SelectionMask,   // 未羽化，蚂蚁线与 bounds 都基于它
    pub feather: f32,          // 图像像素，0 = 关
}
impl SelState { pub fn effective(&self) -> Cow<SelectionMask> { /* 有 feather 才模糊 */ } }
```

消费端（抠图 / 删除）取 `effective()`；outline / 手柄取 `mask`。
边界、平滑作用于 `mask`（未羽化），**与 PS 的「先羽化再边界」有细微差异**，文档与状态栏文案注明即可。

## 3. 算法规格

所有算子都是 `bounds` 内 O(n) 逐像素，`w*h <= 6000万` 在 release 下均 < 100 ms。

| 功能 | 语义 | 实现 |
|---|---|---|
| **反选** | 全画布减去当前选区（含洞） | `alpha' = 255 - alpha`，`bounds = canvas`。两次反选可还原 |
| **边界(k)** | 沿原边缘生成总宽 k 的环（内外各 k/2） | 对二值 mask 做距离变换（Felzenszwalb 精确 EDT，两遍扫描），保留 `0 < dist <= k/2` |
| **平滑(k)** | 抹掉边缘锯齿、圆角化 | 半径 k 的 box blur ×3（近似高斯）→ 阈值 `>=128` 二值化 → 可选 1 次 3×3 中值去毛刺 |
| **羽化(r)** | 软边过渡 | 半径 r 的 box blur ×3，**不阈值化**，存 `feather` 参数 |

**轮廓提取（蚂蚁线）**：二值化 `alpha>=128` → Marching Squares 追踪所有闭合环（外环 + 洞），合并共线段 → `Vec<Vec<[f32;2]>>`（画布坐标）。
降采样：按 `max(1, round(1/preview_scale))` 的步长取点，避免大图全分辨率追踪（6400 万像素即使 release 也要几百 ms）。视觉上蚂蚁线本就 1px，降采样无感。

**光栅化**：`Rect` 直填；`Ellipse` 用 `(dx/rx)²+(dy/ry)²<=1`；`Polygon` 用 scanline 奇偶填充（与现有 `Selection::contains` 的射线法语义一致，保证测试可对照）。

## 4. 交互规格

### 4.1 四种工具

| 工具 | 快捷键 | 起手 | 结束 | 约束 |
|---|---|---|---|---|
| 矩形 | `M` | 拖拽 | 松手 | `Shift` 正方形，`Alt` 从中心 |
| 椭圆 | `Shift+M` | 拖拽（外接矩形） | 松手 | 同上 |
| 套索 | `L` | 按住自由拖 | 松手自动闭合 | 采点间距 >= 2 显示像素，RDP 简化 ε=0.75 |
| 多边形套索 | `Shift+L` | 单击加点 | 双击 / `Enter` / 点回起点(<=6px) | `Shift` 约束 45°，`Backspace` 删上一点，`Esc` 放弃 |

- 工具条 `SelectionBar.qml`：4 个 `IconButton`（复用现成 widget），浮在画布左上，`selTool` 高亮。默认 `"rect"` —— **不改现有「拖拽即框选」的手感**。
- 工具互斥：`markTool != "none"` 时选区工具不接管拖拽（现有 `markMa` 优先级不动）。激活标记工具会顺手把 `selTool` 归 `"rect"`。
- 手势期间 `selRubberBanding` 概念泛化为 `selGestureActive`（吞滚轮缩放、隐藏手柄），沿用 `EditorContent.qml:130` 的 `modeActive`。
- 多边形套索需要「未闭合中」状态：`polyPts` 存在 QML，画一条跟随鼠标的预览线 + 每个顶点点小方块；此状态下滚轮缩放禁用、`Esc` 只取消本次加点（不冒泡到清选区）。

### 4.2 选区与后续操作

| 操作 | 行为 |
|---|---|
| 选区内部拖动 | 移动选区本身（PS 默认），`mask` 平移，`shape` 同步平移 |
| `EdgeHandles` | 仅 `Rect`/`Ellipse` 显示（PS 里套索没有手柄）；拖动 = 重建 mask |
| 复制 / 剪切 / 删除 / 提取 | **选区保留**（PS 语义，本次改为持久）；删除走 `effective()` 的 alpha 混合 |
| `Ctrl+K` 裁剪 | 用 `mask.bounds`（矩形裁剪），随后**清空选区**（画布尺寸变了） |
| `Ctrl+A` | 全画布 `Rect` |
| `Ctrl+D` / 右键「取消选择」 | 清空，`feather` 一并重置 |
| `Esc` | 多边形加点中 → 只取消加点；否则清选区（现有优先级链末尾插入） |

### 4.3 右键菜单（本次核心交付）

- 命中规则：右键点在 `mask` 内（`alpha>127`）→ 弹菜单；点在选区外 → 不弹（PS 同）。
- 实现：`selDragMouse` 增加 `acceptedButtons: Qt.LeftButton | Qt.RightButton`，`onPressed` 里右键分支打开 `SelectionMenu.qml`（复用 `MenuRow`，风格对齐 `OverflowMenu.qml`），坐标钳制在窗口内。
- 菜单项顺序与 PS「选择」菜单一致：

```
取消选择        Ctrl+D
选择反选        Ctrl+Shift+I
─────────────
边界…           1~100 px
平滑…           1~100 px
羽化…           0~250 px
```

- 边界/平滑/羽化 → `SelectionOpDialog.qml`：标题 + 数值滑杆（对数手感，1~100）+ 数字输入 + 实时说明（「羽化 8 px：边缘 8 px 内做透明渐变」）+ 确定/取消。默认值 边界 4 / 平滑 4 / 羽化 8。
- 应用后：Rust bump `version` → QML 刷新；状态栏提示「已羽化 8 px」。

### 4.4 蚂蚁线渲染

`SelectionOutline.qml`（新增）：`Canvas` + `Path2D`，黑白双色 dash（8/8）交替、`lineDashOffset` 由 `Timer(120ms)` 步进做流动。

- 用 `Canvas` 而非 `QtQuick.Shapes`：项目已有 Canvas 先例（`CanvasSurface.qml:444` 的标记预览），且 `Path2D.setLineDash/lineDashOffset` 现成。
- **坑位（项目历史）**：绝不在 `onPaint` 里触发自身的 `requestPaint`；流动只改 `lineDashOffset` 后 `requestPaint()`，且 `renderStrategy: Canvas.Immediate`。选区不变时不重绘（`sel_version` 未变即跳过）。
- 两层：黑实线打底 + 白虚线覆盖，保证在任意底色上都可见（PS 同款）。

## 7. 测试用例（P0 必过）

1. `rect_mask_matches_contains` — 随机点比对 `Selection::contains` 与 mask alpha，确保光栅化与原语义一致。
2. `ellipse_mask_excludes_corners` — 四角 alpha=0、中心 255。
3. `polygon_scanline_matches_ray_cast` — 同上，用凹多边形 + 自交多边形。
4. `invert_twice_is_identity` — 两次反选后 mask 与原始逐字节相等。
5. `invert_bounds_is_canvas` — 反选后 bounds = 整画布，洞处 alpha=0。
6. `border_ring_width` — 单像素边界的矩形，`border(10)` 后环带宽度落在 [9,11]。
7. `smooth_reduces_stair_steps` — 锯齿阶梯多边形的周长/角点数下降。
8. `feather_edges_are_soft` — 边缘 alpha ∈ (0,255)，中心仍 255，`feather=0` 时逐字节不变。
9. `feather_larger_than_selection_does_not_panic` — r > 短边。
10. `erase_with_feather_produces_partial_alpha` — 删除后边缘是半透明而非全透明。
11. `outline_closed_and_multi_ring` — 反选（含洞）返回 2 条闭合环。
12. `mask_clipped_to_canvas` — 选区超出画布时不越界。

## 8. 风险与坑（项目历史踩过的）

1. **QML 属性遮蔽**：`SelectionViz.qml` 里子组件已有 `host: host` 自引用事故史 —— 新组件一律 `host: view.host` 形式显式取 id。
2. **同一元素只能有一个 `Component.onCompleted`**；重复写会在 qmlcachegen 阶段炸。
3. **build.rs 只监听目录 mtime**：新增 QML 后若类型找不到，先确认 `cargo` 有 `Compiling imageedit-ui`。
4. **Canvas 重绘重入**：`onPaint` 内禁止 `requestPaint`/`toDataURL`。
5. **`selX/selW` 引用点 30+ 处**：改造时用「绑定替代赋值」，编译期抓不到，只能靠 grep `selW`/`selH` 逐处核对 + 手测。
6. **`EditOp::EraseBasePixels` 载荷变大**：mask 进 undo 快照，大图反选后一次 undo 会存 64 MB。缓解：快照里只存 `bounds+alpha`，且 `bounds` 已是局部；反选后确实整幅，可接受（现有 `DocumentSnapshot` 本就更重）。
7. **debug 构建慢**：EDT/模糊在 debug 下大图可能秒级，验收以 release 数据为准；开发期用 ≤2000px 测试图。
8. **`Ctrl+L` 已被「逆时针旋转」占用**（`EditorContent.qml:426`），套索只能用裸 `L`。

### 10.2 与规划的三处偏离

1. **不用弹窗**：边界/平滑/羽化直接在右键菜单里带数值框（含上下箭头 + 方向键微调），改完即刻生效，省掉「确定/取消」。
2. **快速蒙版是视图态**：只改预览位图，不碰文档像素；选区一清空就自动关掉（否则下次建选区会莫名处于蒙版态）。
3. **多边形模式在第一个点锁定**：中途松掉 Shift/Alt 不会改变加/减/交意图。

### 10.3 实施中修掉的实际 bug

- 距离变换用 `f64::INFINITY` 当初始值 → `INF-INF=NaN`，边界算子产出全 0：改成有限大值。
- 布尔运算后 `bounds` 没收紧 → 尺寸徽标报「两框并集」的错误尺寸：`combine()` 末尾 `crop_to_content()`。
- 套索闭环时起点≈终点，用端点距离判「是否拖动过」会把套索误判成单击并清空选区：改用轨迹包围盒。
- `LayerPanel` / `ResizeOverlay` 里还在写只读的 `host.selW=0`：改成 `bridge.sel_clear()`。
- 蚂蚁线原本白虚线叠黑实线，浅色照片上整圈发虚：改成白实线打底 + 黑虚线在上。
