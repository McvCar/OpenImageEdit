# 交互改进方案 — 对齐 macOS 预览（Preview）的选区 / 裁剪 / 粘贴交互与快捷键

> 状态：**已实施**（2026-10-17：D1–D5、D7 均按推荐项 A 落地；交互决策点与快捷键已全部实现，待人工目视验收 §7 清单中的点击/拖拽项）  
> 范围：仅 QML 交互层（`crates/ui/qml/main.qml`）为主，bridge 微调，core 零改动  
> 日期：2026-10-17



---

## 1. 背景与问题

当前实现采用「模式开关」范式：裁剪 / 框选 / 移动三个模式互斥，每次操作都要「进入模式 → 操作 → Esc 退出」。与 macOS 预览（Preview）的「工具 + 即时对象操作」范式相比，主要差距：

| #  | 问题        | 现状                                      | Preview 行为                                |
| -- | --------- | --------------------------------------- | ----------------------------------------- |
| P1 | 选区是一次性参数  | 拖框松手得到静态矩形，只能手柄改大小，不能拖动挪位；Esc 清除        | 选区是**常驻活动对象**：可拖动挪位、可反复精修，Esc/点外部才消失      |
| P2 | 粘贴定位绕远路   | `Ctrl+V` 直接落图层栈（+12px 扇出），定位需再切「移动模式」拖动 | 粘贴后内容处于**浮动落位态**，立即拖动定位，点击外部/回车落定         |
| P3 | 模式互斥打断操作流 | 裁剪/框选/移动三模式互斥切换                         | 无模式概念，选区工具常驻，随时拖框                         |
| P4 | 裁剪确认打断    | 拖框 → 浮层 → Enter 应用                      | 选区常驻 + `Cmd+K` 直接裁剪，无浮层（动作即确认，`Cmd+Z` 兜底） |
| P5 | 缺少操作反馈    | 选区无尺寸读数、无拖动提起感                          | 实时 W×H 像素读数、内容提起视觉反馈                      |

## 2. 改进总览（改动前后对比）

| 操作     | 现在                    | 改后（对齐 Preview）                                                |
| ------ | --------------------- | ------------------------------------------------------------- |
| 建立选区   | 进「框选」模式 → 拖框 → Esc 退出 | **随时**在画布空白处拖框即建选区（无需进模式）                                     |
| 调整选区   | 手柄缩放                  | 手柄缩放 + **框内拖动 = 移动选区**（新增）；手柄样式统一为**蓝色圆点**（见 §4.7）    |
| 选区消失   | Esc                   | Esc 或点选区外空白处（新增点外部消失）                                         |
| 裁剪     | 「裁剪」模式拖框 → 浮层 Enter   | 对**常驻选区**按 `Enter` 或点工具栏「裁剪」直接应用；拖框过程中浮层仍提示（见决策点 D2）          |
| 复制/剪切  | `Ctrl+C/X`（不变）        | 不变                                                            |
| 粘贴     | `Ctrl+V` 直接入栈         | `Ctrl+V` 入栈并**自动进入拖动落位态**，松手/点击外部/回车落定；再次 `Ctrl+V` 落定当前并粘贴下一个 |
| 移动图层   | 「移动」模式拖动              | 画布上**直接拖动选中图层内容区域**移动（命中测试）；或保留快捷键 `V`（见决策点 D1）               |
| 缩放图层   | 无                     | **选中图层显示 4 角 4 边蓝色圆点手柄**，拖动手柄缩放图层（需 core 新增 `ScaleLayer` op，见 §4.4 / 决策点 D5） |
| 删除选区像素 | `Delete`              | 不变                                                            |
| 工具栏    | 裁剪 / 框选 / 移动 三按钮      | 「选择」常驻概念化：裁剪按钮（有选区时可用）+ 移动按钮可精简为辅助（见决策点 D1）                   |
| 快捷键    | Windows 风格（左转 `Ctrl+Shift+R`、适应 `Ctrl+0`、实际 `Ctrl+1`…） | **整体对齐 Preview**（§4.6）：左转 `Ctrl+L`、实际大小 `Ctrl+0`、适应 `Ctrl+9`、裁剪 `Ctrl+K`、重做 `Ctrl+Shift+Z`、关窗 `Ctrl+W`、退出 `Ctrl+Q` |

## 3. 新交互状态机（QML 侧设计）

废弃 `cropMode / selectionMode / moveMode` 三个互斥布尔，改为：

```
常驻选区 selExists（唯一事实来源）
 ├─ selAdjusting   拖框中 / 手柄精修中（临时态）
 ├─ (Enter 或「裁剪」按钮) → 执行 crop_to → 选区清除 → 可 Ctrl+Z
 └─ (Esc / 点外部) → 选区清除

粘贴落位态 pasteFloating
 └─ Ctrl+V → 图层入栈并选中 → 拖动改 offset（复用 drag_translate_begin/update/end 实时预览）
      ├─ 点击画布其他位置 / Enter / 下一次 Ctrl+V → 落定（仅退出拖动态）
      └─ Esc → 撤销本次粘贴（undo），回到粘贴前状态
```

- 选区与图层拖动通过**命中测试**区分（见决策点 D1），不再有模式开关。
- `Esc` 分发优先级重排为：落位态 > 选区精修中 > 常驻选区 > 图层面板 > 全屏。
- 全屏（F11）与模式无关，保持现状。

## 4. 详细交互规范

### 4.1 选区（常驻）

1. 在画布空白处（未命中任何选区/图层框）按下拖动 → 新建选区；拖动中实时高亮。
2. 松手后选区保留（marching-ants 样式 + 8 向手柄）；旁侧显示 `W × H` 像素读数（新增，P5）。
3. 手柄拖动 = 缩放（吸附图像像素边界，沿用现有 `snapDisplay`）；**框内拖动 = 整体移动选区**（新增）。
4. 点击选区外 → 选区消失；`Esc` → 选区消失；重新拖框 → 覆盖旧选区。

### 4.2 裁剪

1. 有常驻选区时：按 `Enter` 或点工具栏「裁剪」→ 执行 `crop_to`（现有 core op），选区随之清除，`Ctrl+Z` 可回滚。
2. 拖框/精修过程中，选区下方显示轻量提示条「Enter 应用裁剪 · Esc 取消」（替代现有大型浮层，见决策点 D2）。
3. 无选区时「裁剪」按钮置灰；`Enter` 无操作。

### 4.3 复制 / 粘贴

1. `Ctrl+C` / `Ctrl+X`：有常驻选区 → 作用于选区像素；无选区但有选中图层 → 作用于整层（沿用现状）。
2. `Ctrl+V`：
   - 图层入栈并自动选中（沿用 `paste_clipboard`）；
   - 立即进入**拖动落位态**：鼠标拖动即实时移动该图层（复用 `drag_translate_begin/update/end`，70ms 节流实时预览不变）；
   - 落定动作：点击画布其他位置 / `Enter` / 再次 `Ctrl+V`（落定当前并粘贴下一个，扇出偏移只作用于未拖动过的连续粘贴）；
   - `Esc`：撤销本次粘贴并退出落位态。
3. 跨窗口粘贴行为不变（进程级剪贴板）。

### 4.4 图层移动与缩放

- **画布拖动命中测试**（新增）：
  1. 命中「选中图层内容区域」（`selLayerBox`，layers_json 已有 x/y/w/h）→ 拖动移动图层内容（复用现有 drag_translate 链路）；
  2. 命中选区框（边框带 / 框内）→ 移动选区；
  3. 其他 → 新建选区。
- 方向键微调、Shift±10px 保持不变。
- 是否保留工具栏「移动图层」按钮见决策点 D1。

- **选中图层缩放（新增，用户需求 2026-10-17）**：
  - 选中图层在画布上显示虚线包围框 + **4 角 4 边蓝色圆点手柄**（样式同 §4.7）；
  - 拖角/边手柄 → 实时只更新**目标虚线框**（显示层预览），松手一次性重采样提交（避免逐帧 Lanczos 卡顿）；
  - 提交调用 core 新增 op：`ScaleLayer { index, from: DocumentSnapshot, new_w, new_h }`（Lanczos3 重采样，复用 `render` crate 的 resize 路径），入撤销栈可 `Ctrl+Z` 回滚；
  - 角点默认等比还是自由缩放见决策点 D5；边手柄始终单轴自由；
  - 缩放后 layers_json 的 bounds 刷新，后续拖动/微调以新 bounds 为准。

### 4.7 选中态样式规范（新增，用户需求 2026-10-17）

统一由 `EdgeHandles` 组件提供，选区框与选中图层框共用：

| 元素 | 样式 |
| --- | --- |
| 选区框（虚线选区） | 1.5px 虚线边框，颜色 `#5b9dff`（沿用现选中色） |
| 选中图层框 | 1.5px 虚线边框，颜色 `#5b9dff` 66% 透明度（与选区区分层级） |
| 手柄（4 角 + 4 边） | **蓝色圆点**：直径 10px（显示坐标），填充 `#5b9dff`，白色描边 1.5px，投影 1px 模糊——表示当前处于选中状态 |
| 手柄 hover | 直径放大到 12px；光标：角点 = 斜向双箭头（↖↘ 等），边中点 = 水平/垂直双箭头 |
| 拖动中 | 被拖手柄保持放大，对应边显示实时像素读数（选区显示 W×H） |
| 尺寸读数 | 选区/图层框右下角跟随显示 `W × H` 像素 |

注意：手柄命中区（≥14px）大于视觉圆点，便于点中；显示坐标与图像像素经 `snapDisplay` 换算，与现有吸附逻辑一致。

### 4.8 图层面板重构（新增，用户需求 2026-10-17）

| # | 需求 | 方案 |
| --- | --- | --- |
| L1 | 主图层也显示在列表里 | `layers_json` 增加主图层条目，显示在列表**最底部**（显示序 = 顶层在前），名称固定「背景」；主图层行**不可拖动排序、不可删除**，仅展示与高亮信息 |
| L2 | 允许调整图层顺序 | 面板行**拖拽排序**：拖动行时显示插入位置指示线，松手调用 `reorder_layer(from, to)` 一次入撤销栈（`Ctrl+Z` 整步回滚）；主图层行拖不动 |
| L3 | 图层命名用产生顺序数字 | 新图层（提取/粘贴）按**会话内全局递增序号**命名：`1`、`2`、`3`…（复制粘贴与提取共用同一计数器）；双击行内名称重命名保留 |
| L4 | 列表内删除图层 | **键盘 `Delete` / `Backspace` 删除选中图层**；优先级：有选区 → 删除选区像素（现有语义）；无选区且选中普通图层 → 删除该图层；选中主图层 → 无操作 |
| L5 | 去掉底部按钮 | 移除面板底部「上移 / 下移 / 显隐 / 删除」四个按钮（排序靠拖拽、删除靠键盘、显隐靠眼睛图标）；底部仅保留**不透明度滑条**（作用于选中图层） |
| L6 | 选中行高亮 | 保留现有高亮（选中行底色 `#3d5a80`），拖拽经过的行给浅色悬停反馈 |
| L7 | 眼睛图标开关隐藏 | 行左侧 16px 命中区为**眼睛图标**（QML Canvas 自绘睁眼/闭眼-斜线两态，不引入图标资源），点击切换该图层可见性；主图层行的眼睛见决策点 D7 |

主图层条目格式约定：`layers_json` 中主图层以 `"base": true` 标记、`"n": "背景"`，排在数组末尾（显示序最底）；QML 依据 `base` 标记禁用拖拽/删除，普通图层序号 `i` 语义不变（bridge `select_layer` / `delete_selected` 等接口不受影响）。

## 5. 待确认决策点（确认后按此实施）

> 快捷键方案（§4.6）已按用户要求确定对齐 Preview，不再作为决策点；以下 4 项仍待确认。

- **D1 框内拖动语义**：
  - **A（推荐）**：命中测试自动分发——拖选中图层内容 = 移动图层，拖选区其他部分 = 移动选区；工具栏「移动」按钮移除；
  - B：保留「移动」按钮作为显式工具（选中它时框内拖动 = 移动图层，否则移动选区）。
- **D2 裁剪确认**：
  - **A（推荐）**：保留轻量提示条（Enter/Esc），比 Preview 的 Cmd+K 多一步提示但对新手更明确；
  - B：完全对齐 Preview——无任何提示，直接 Enter 裁剪（更激进）。
- **D3 粘贴后按 Esc**：
  - **A（推荐）**：撤销本次粘贴（回到粘贴前）；
  - B：仅退出拖动态，粘贴保留（更简单，但「误粘贴」需要手动 Ctrl+Z）。
- **D4 选区点外消失**：
  - **A（推荐）**：点选区外立即消失（Preview 行为）；
  - B：点外不消失，仅 Esc 消失（避免误触丢失选区）。
- **D5 图层角点缩放比例**（新增）：
  - **A（推荐）**：角点默认等比缩放（符合直觉），按住 `Shift` 临时自由缩放；边中点始终单轴自由；
  - B：角点默认自由缩放，按住 `Shift` 等比。
- **D7 主图层的眼睛**（新增）：
  - **A（推荐，v1 简单）**：主图层行眼睛**置灰不可点**——隐藏底图会牵连渲染快路径（无可见图层时直接缩放底图）与 `flatten()` 合成逻辑，收益低；
  - B：支持隐藏主图层（core 增 `base_visible` 标志，composite/flatten/save 全链路适配，画布显示透明棋盘格）。

## 6. 技术改动点与影响面

| 模块                        | 改动                                                                                               | 规模                  |
| ------------------------- | ------------------------------------------------------------------------------------------------ | ------------------- |
| `crates/ui/qml/main.qml`  | 状态机重构（3 互斥布尔 → 常驻选区 + `selAdjusting` + `pasteFloating`）；拖动命中分发；Esc/Enter 分发重排；提示条替换浮层；工具栏调整；快捷键对齐 Preview（§4.6，约 10 处 `Shortcut` 调整 + 新增 `Ctrl+W/Q/K/L/0/9`）；**选中态蓝点手柄样式 + 尺寸读数（§4.7）+ 选中图层缩放拖拽** | 主要工作量，约 450–550 行增改 |
| `crates/ui/src/bridge.rs` | 基本不动；仅当 D1-A 需要时补一个 `hit_layer(x, y)` invokable（也可纯 QML 用 layers_json 的 bounds 本地判定，倾向后者，零改动）    | 0–20 行              |
| `crates/core/src/lib.rs` | **新增 `EditOp::ScaleLayer`**（图层缩放，Lanczos3 重采样 + 快照回滚）+ `Document::scale_layer()` + 单元测试；**确认 `move_layer` 为单步 op 供拖拽排序复用**（若现为 up/down 语义则补 `reorder(from, to)`）；约 80–120 行 + 3–4 项测试 | 中 |
| `crates/ui/src/bridge.rs` | `scale_selected_layer(w, h, keep_ratio)` invokable；**`reorder_layer(from, to)` invokable**；**图层命名改为会话内递增序号**（提取/粘贴共用计数器）；**`layers_json` 增加主图层条目**（`base:true`，末尾）；dirty 维护（约 60–90 行）；D1-A 命中测试倾向纯 QML（layers_json 本地判定，零改动） | 中 |
| `scripts/`、selftest 链路    | `--script=` op 全部不变，回归不受影响；可顺手加 `scale-selected:W,H` 脚本 op 供自测 | 0–10 行 |

风险控制：core 仅新增独立 op（不改现有 op），撤销栈模式与 ResizeDocument 一致；旧快捷键不破坏。

## 7. 验收清单（实施后人工验证）
