## 0. 先读：这一轮到底改了什么

**P0-1 已接线**：`Layer` 新增 `transform: Option<LayerTransform>`（保留未插值原图）、`EditOp::SetLayerTransform`、**图层缩放改为从原始像素重新采样**、写像素前自动烘焙。

**P0-2a（本轮）修了首轮复测的 3 个问题**：
1. **文字/细线缩放还原不了原来清晰** → 根因：`image::imageops::resize` 即使用 `80→80` 也会跑一遍 Lanczos3，负旁瓣把单像素笔画抹软。现改为**回到原始尺寸直接 1:1 索引拷贝**，并允许手柄换算的 **±2px 误差吸附**（带镜像不吸附，redo 幂等）。
2. **选中图层按 Del 没反应** + 3. **点击图层没取消框选选区** → 同一根因：残留选区让 `onDeleteKey` 抢先走「删除选区像素」。现在**点中图层时清掉残留框选**；但 `layerPickAt` 保证「按在选区内部」仍由选区手势优先，不打断重叠工作态。

**P0-2b1（本轮）**：把移动 / 八向缩放 / 旋转的 live 临时态收成**一个互斥的 `TransformSession`**（类型层面不可能同时残留两套预览帧），预览合成改成一个分派点；**落定语义、QML 手势、所有旧快捷键与交互一律没动**，所以 A 组结果应与 P0-2a 版逐项一致。另修好 **V 键**：以前单字母快捷键的 `enabled` 绑定在组件创建期求值失败、被 QML 丢弃后永久 false，表现为按 V / M / L / W / J / G 全部没反应；现在切换移动工具会有一句 1.3s 的提示。

**P0 收尾（本轮）：四个阶段一起交付**

- **P0-2b2**：手势三件套 `transform_begin/update/end` 成为唯一入口；移动 / 缩放 / 旋转的**落定统一成一条参数化历史**（`SetLayerTransform`，`source` 恒为未插值原图）——所以「转几次 45° 框越来越大」「旋转累积模糊」「旋柄转完再改角度变糊」这三个老问题从机制上消失。另有 **Tier 1 GPU 快路径**：移动手势起手时生成「静态层 + 活动层」两张纹理，拖动帧只改活动层的位置/尺寸/不透明度，**不再每帧全幅合成**。
- **P0-3**：去掉图层框的四边钳制 —— 图层可以拖出画布、四边拉伸不被边缘挡；画布外不渲染像素（只留控件）。
- **P0-4**：智能参考线 —— 8 显示像素阈值、洋红提示线 + 距离数值、双轴同时吸；`显示参考线` / `智能吸附` 两个开关独立，重启记住。
- **P0-5**：变换数值面板 —— MarkBar 最右的 `⊞` 按钮唤起（默认隐藏，重启记住）；X/Y/W/H 是**变换后轴对齐外接框**；改数值与拖拽等价、只留一条历史。

> ⚠️ 本轮改动面比前几轮大，重点看 **A14（手势与 GPU 快路径）** 和 **A5 整组**；A15/A16/A17 是新增能力，按项测。
> ⚠️ 数值面板当前在 settings.ini 里是「显示」状态（我做截图核对时打开的），直接开图就能看到；点标题栏 `✕` 关掉后重启应保持关闭（D13）。
> A 组是长期基线：P1-A 每完成一阶段，照它复跑一遍。

优先级：先测 **§A14 P0-2b2 专项（手势与 GPU 快路径，本轮最优先）** → **§A15 去钳制** → **§A16 智能参考线** → **§A17 数值面板** → **A5 图层与变换整组** → **A13 V 键** → **A12 / A11** → **A3 缩放/DPI** → **A8-3 导出尺寸**，其余按序。
